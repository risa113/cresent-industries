# Crescent Engineering Industries — Enterprise Architectural Portal

[![Deploy to GitHub Pages](https://github.com/risa113/cresent-industries/actions/workflows/deploy.yml/badge.svg)](https://github.com/risa113/cresent-industries/actions/workflows/deploy.yml)

> High-precision, structural-minimalist digital presence and interactive engineering portal for Crescent Engineering Industries (Division: Crescent Roofing Systems). Engineered for 100% mobile responsiveness, ISO 9001:2015 compliance display, and CAD/BIM specification exploration.

🌐 **Live Website**: [https://risa113.github.io/cresent-industries/](https://risa113.github.io/cresent-industries/)

---

## 🏗️ Architectural Overview & Features

- **100% Mobile Responsive**: Tested and optimized across every breakpoint from 320px mobile viewports to 4K ultra-wide displays.
- **Fluid & Scaled Typography**: Uses Swiss-inspired architectural typography combining *Plus Jakarta Sans* and *Inter*.
- **CAD Blueprint Board**: Interactive technical CAD schematic with touch-friendly annotation selectors for rafter trusses, purlin grids, and foundation embeds.
- **11 Core Structural Disciplines**: Dynamic categorized views for Pre-Engineered Buildings (PEB), Heavy Structural Steel, Tensile Roofing, PUFF Panels, and Cold Storage.
- **Architectural Case Archives**: Filterable bento grid portfolio with steel tonnage and square footage metrics.
- **Instant RFP Engineering Desk**: Built-in Request For Proposal form with field validation and direct communication links.
- **Mobile Bottom Quick Actions**: Dedicated 1-tap Call and Quote actions for smartphone users.

---

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler & Build Tool**: Vite
- **Styling**: Tailwind CSS v3 with custom CAD grid utilities
- **Icons & Typography**: Google Fonts (Plus Jakarta Sans, Inter) & Material Symbols Outlined
- **Deployment**: GitHub Pages via GitHub Actions

## 🚀 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/risa113/cresent-industries.git
   cd cresent-industries
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
